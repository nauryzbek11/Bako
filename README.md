# Ұзату тойы — Цифровое приглашение

Главный экран показывает четыре фотографии `CONTENT/photos/photo01.jpg`–`photo04.jpg`
с плавной сменой каждые 6,5 секунды. Заменяйте эти файлы своими фотографиями;
список находится в `CONTENT/content.js`. Перед галереей добавлено видео
`CONTENT/video/main-video.mp4`; путь задаётся в поле `video` в `CONTENT/content.js`.
Видео оптимизировано для телефона: 720×1280, H.264/AAC, около 6 МБ.
Видео запускается кнопкой, при просмотре фоновая музыка приостанавливается.
Кнопка внизу слева останавливает смену фото. Стрелка в верхнем левом углу
появляется при прокрутке и возвращает на главный экран.
При включённом системном уменьшении движения автоматическая смена отключена.

Современное luxury-приглашение для **Балнұр** на ұзату тойы.\
Дата: **24 Қазан 2026 · 17:00 · ShahHall мейрамханасы · Жалағаш**\

## 1. Установка Node.js

1. Зайди на **https://nodejs.org**
2. Скачай версию **LTS** (рекомендуемую)
3. Запусти установщик и следуй инструкциям
4. После установки проверь в терминале:
   ```
   node --version
   npm --version
   ```
   Должны показаться версии (например, v20.x.x)

---

## 2. Открытие в VS Code

1. Открой **VS Code**
2. В меню выбери: **File → Open Folder**
3. Выбери папку `uzatu-invitation`
4. Откроется весь проект

---

## 3. Установка зависимостей

В VS Code открой терминал: **Terminal → New Terminal**

Выполни команду:
```bash
npm install
```

Это установит все необходимые пакеты (Express, SQLite, JWT и др.).

> **Примечание**: После установки появится папка `node_modules`. Не удаляй её.

---

## 4. Запуск сервера

В терминале выполни:
```bash
npm start
```

Или для разработки (автоперезапуск при изменениях):
```bash
npm run dev
```

> Для `npm run dev` нужно установить nodemon:
> ```bash
> npm install -g nodemon
> ```

После запуска в терминале появится:
```
🎉 Ұзату тойы — Сервер запущен!
🌐 Сайт: http://localhost:3000
⚙️  Админка: http://localhost:3000/admin
```

Открой браузер и перейди по адресу: **http://localhost:3000**

## Как менять данные

### Все данные мероприятия — в одном файле

Открой файл: `CONTENT/content.js`

```javascript
const invitation = {
  brideName: "Балнұр",        // ← Имя сестры
  date: "24 қазан",           // ← Дата (текст)
  time: "17:00",               // ← Время
  dateTime: "2026-10-24T17:00:00", // ← Для таймера
  locationName: "ShahHall мейрамханасы", // ← Название зала
  city: "Жалағаш кенті",      // ← Город
  hosts: "Абзал – Мария",     // ← Той иелері
  invitationText: "...",       // ← Текст обращения к гостям
};
```

### Где менять имя сестры

В файле `CONTENT/content.js`:
```javascript
brideName: "Балнұр",  // Замени на нужное имя
```

### Где менять дату и время

В файле `CONTENT/content.js`:
```javascript
date: "24 қазан",
time: "17:00",
dateTime: "2026-10-24T17:00:00",  // ← ISO формат для таймера
```

### Где менять адрес и карту

В файле `CONTENT/content.js`:
```javascript
locationName: "ShahHall мейрамханасы",
city: "Жалағаш кенті",
map: {
  latitude: 45.0153,   // ← Координаты (найди в Google Maps)
  longitude: 64.0878,
  label: "ShahHall мейрамханасы, Жалағаш",
},
```

**Как найти координаты в Google Maps:**
1. Открой Google Maps
2. Найди ShahHall
3. Нажми правой кнопкой мыши на точку
4. Выбери «Что здесь?»
5. Скопируй числа (например: 45.0153, 64.0878)

### Где добавлять фотографии

1. Скопируй фото в папку `CONTENT/photos/`
2. Назови файлы: `photo01.jpg`, `photo02.jpg`, `photo03.jpg` и т.д.
3. В файле `CONTENT/content.js` добавь пути:
   ```javascript
   photos: [
     "CONTENT/photos/photo01.jpg",
     "CONTENT/photos/photo02.jpg",
     "CONTENT/photos/photo03.jpg",
     // Добавляй сюда новые
   ],
   ```

**Рекомендуемый размер:** 1200×800 пикселей, формат JPG, не более 2 МБ каждый.

### Где добавлять видео

1. Скопируй видео в папку `CONTENT/video/`
2. Назови файл: `main-video.mp4`

**Рекомендации:**
- Формат: MP4 (H.264)
- Разрешение: 1080p максимум
- Размер: не более 50 МБ (для быстрой загрузки)

### Где добавлять музыку

1. Скопируй музыку в папку `CONTENT/music/`
2. Назови файл: `music.mp3`

**Рекомендации:**
- Формат: MP3
- Длительность: может быть любой (включён loop)
- Размер: не более 5 МБ

## Пароли и безопасность

Все пароли хранятся в файле `.env`:

```
GUEST_LIST_PASSWORD=your_private_guest_password # Задай свой пароль
ADMIN_PASSWORD=your_private_admin_password     # Задай другой пароль
JWT_SECRET=your_long_random_secret             # Сгенерируй длинный случайный ключ
```

> ⚠️ **ВАЖНО**: Никогда не отправляй файл `.env` в интернет (GitHub, облако и т.д.)

### Как изменить пароль

Открой `.env` и измени нужную строку:
```
GUEST_LIST_PASSWORD=НовыйПарольГостей
ADMIN_PASSWORD=НовыйПарольАдминки
```

После изменения перезапусти сервер (Ctrl+C → `npm start`).

## Публикация в интернете

### Вариант 1 — Railway (бесплатно, просто)

1. Зайди на **https://railway.app**
2. Зарегистрируйся через GitHub
3. Нажми «New Project» → «Deploy from GitHub repo»
4. Выбери репозиторий
5. В настройках добавь переменные из `.env`:
   - `GUEST_LIST_PASSWORD`
   - `ADMIN_PASSWORD`
   - `JWT_SECRET`
   - `PORT=3000`
6. Railway автоматически запустит `npm start`

### Вариант 2 — VPS сервер

1. Загрузи файлы на сервер (без `node_modules`)
2. Выполни `npm install`
3. Создай `.env` с паролями
4. Запусти через PM2:
   ```bash
   npm install -g pm2
   pm2 start server/server.js --name uzatu
   pm2 save
   ```

### Перед публикацией обязательно:

- Поменяй все пароли в `.env` на сложные
- Убедись что `.env` не загружен в репозиторий
- Проверь что `JWT_SECRET` длинный и случайный

## Часто задаваемые вопросы

**Сайт не открывается?**
- Убедись что сервер запущен (`npm start`)
- Проверь что открываешь `http://localhost:3000`, а не файл напрямую

**Музыка/видео не воспроизводятся?**
- Проверь что файлы находятся в правильной папке
- Для музыки: нужно сначала нажать на печать конверта

**Форма не отправляется?**
- Сервер должен быть запущен
- Проверь консоль браузера (F12) на ошибки

**Таймер показывает неправильно?**
- Проверь `dateTime` в `CONTENT/content.js`
- Формат: `"2026-10-24T17:00:00"`
